# New Astro portfolio

This directory contains the new static Astro portfolio experience. The original Create React App application remains at the repository root as legacy material and is not modified by this site.

## Local development

```sh
cd astro
npm install
npm run dev
```

## Checks

```sh
npm run check
npm run build
```

Astro reads the existing repository-level `public/` directory so the original image assets and favicon are reused without moving or rewriting them.
